hipcheck

Broken paths and dead nodes. Found in one click.坏路径和无用节点，一键找出。

A small Houdini tool that checks a scene for file paths that will break, and cleans up nodes that do nothing. Ctrl+Z undoes anything it changes.一个小巧的 Houdini 工具：检查场景里会坏掉的文件路径，清理什么也不做的节点。它改过的东西都能 Ctrl+Z 撤回。

What it does它做什么

Find what is broken, clear what is dead. Nothing changes until you say so.找出坏掉的，清掉没用的。你不点头，它什么都不改。

Check

Input files that don't exist, and paths typed as D:/ or //server instead of $HIP / $JOB. Scans the whole hip.不存在的输入文件，以及写成 D:/ 或 //server、而不是 $HIP / $JOB 的路径。扫描整个 hip。

Clean

Floating nodes and unused branches: nodes whose result never reaches anything that matters. Colour them red, look, then delete.散落的节点和无用分支：结果流不到任何有用地方的节点。先标红，看清楚，再删。

Ignore忽略

Keep a stray node on purpose. The mark is saved with the hip, so it stays quiet next time.故意留下的节点就忽略它。标记跟着 hip 保存，下次不会再报。

Ctrl+Z

Deleting rescans first and only removes nodes that are still unused. Every change is one undo step.删除前会先重扫，只删仍然无用的节点。每次改动都是一步撤销。

Never flagged永远不报

  • Parameters still at their default value仍是默认值的参数
  • Output paths of ROPs and caches that write filesROP 和缓存等写文件节点的输出路径
  • Relative paths Houdini finds on its ownHoudini 自己能找到的相对路径
  • Nodes inside locked HDAs, hidden parameters锁定 HDA 里的节点、隐藏参数

Always kept永远保留

  • Display, render, template and footprint flags显示、渲染、模板、足迹标志
  • Nodes named OUT* and file writers名为 OUT* 的节点和写文件节点
  • Locked nodes and nodes with a comment锁定的节点、带注释的节点
  • Anything referenced from elsewhere in the hip在 hip 其他地方被引用的节点

Install安装

It sets itself up from inside Houdini. No config files, no restart.在 Houdini 里自己装好。不用改配置文件，不用重启。

  1. Download the latest release and unzip it somewhere it can stay, e.g. D:/tools/hipcheck.下载最新版本，解压到一个不会被清理的位置，例如 D:/tools/hipcheck。
  2. In Houdini, open Windows → Python Shell.在 Houdini 里打开 Windows → Python Shell。
  3. Paste this line and press Enter:粘贴这一行，按回车：
    p = hou.text.expandString(hou.ui.selectFile(title="Select install.py in the hipcheck folder", pattern="install.py")); p and exec(open(p, encoding="utf-8").read(), {"__file__": p})
  4. In the file browser, pick install.py in the unzipped folder and click Accept. The hipcheck shelf tab appears; click the button.在弹出的文件浏览器里选解压目录中的 install.py，点 Accept。工具架上会出现 hipcheck 标签，点按钮即可。
