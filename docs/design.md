# hipcheck 设计（v1）

2026-11-22 和 Kurt 讨论定稿。独立工具，不依赖 kpipe。

## 运行

- Houdini 内运行的 Python。目标 Houdini 21.0（本机 21.0.512），写法兼容 20.5：Qt 一律通过 `hutil.Qt` 导入，不直接 import PySide2/PySide6。
- 用 Houdini package 安装：`hipcheck.json` 拷进 `$HOUDINI_USER_PREF_DIR/packages`。它设 `HIPCHECK` 变量、把 `$HIPCHECK/python` 加进 PYTHONPATH、把 `$HIPCHECK` 加进 HOUDINI_PATH（让 `toolbar/hipcheck.shelf` 自动载入）。
- 入口：shelf 按钮（快捷键由 Kurt 在 Houdini 的热键管理里绑）。
- 弹窗不锁界面（非模态，父窗口是 `hou.qt.mainWindow()`），带“重新扫描”。同一时间只开一个窗口，再点按钮就把已开的那个拿到前面并重扫。
- 判断逻辑（`scan.py`）和动作（`actions.py`）不依赖 UI，能在 hython 里无界面跑和测试。

## 上半部分：检查（扫整个 hip）

每条结果：问题类型、节点路径、参数名、原因说明。点一行跳到该节点（必要时切换网络编辑器所在层级）。

1. **路径断链**：只查“读”的文件路径。
   - 文件引用类字符串参数（`hou.stringParmType.FileReference`），值为空的跳过。
   - 写出类参数不查：写文件节点（见下文“会写文件的节点”）的输出路径不查，除非该节点处在“从磁盘读”模式（如 File Cache 的 load from disk 打开、File SOP 的 file mode 是 Read/Automatic）。
   - 对当前帧、全局首帧、全局尾帧各求值一次；三个里只要有一个文件存在就算正常。三次值相同只查一次。
   - `op:` 开头的路径：查指向的节点存不存在。
2. **写死的绝对路径**：参数原文（`unexpandedString()`）以盘符（`D:/`、`D:\`）或网络路径（`//`、`\\`）开头就报。原文以变量（`$HIP`、`$JOB` 等）或反引号表达式开头的自然不会命中。

## 下半部分：清理（只管当前这一层，v1 只支持 SOP 网络）

当前层 = 扫描时网络编辑器所在的那一层。不是 SOP 网络、或处在锁住的 HDA 里面时，清理部分显示“这一层不支持”，检查部分照常。

### 终点（它和它的全部上游都保留）

- 显示 flag、渲染 flag、template flag、footprint flag 任一打开的节点
- 名字以 `out` 开头的节点（不分大小写，任何类型）
- 会写文件的节点：File Cache、ROP 类 SOP（类型名含 `rop_` 或 `filecache`，或带 `execute` 按钮参数的节点）
- 锁住的节点（hard lock 或 soft lock）
- 写了注释（comment 非空）的节点
- 被引用的节点（见下）

### 引用（在整个 hip 范围里查）

当前层里，凡是被“这一串之外”的东西引用到的节点都算终点：
- Houdini 自带的依赖关系（`ch()` 等表达式、spare input）
- 字符串参数里写到它：完整路径、`../名字` 这类相对路径、`op:` 路径、节点引用类参数里的名字、wrangle 代码里 `op:` 后面的路径。宁可多保留，不可误删。

### 判断

1. 从所有终点沿输入连线往上游走（所有输入都算，包括 Switch 没选中的输入、经过 bypass 节点的连线；网络 dot 透明穿过），走到的都是“有用”。
2. 剩下的节点按连通性分组（一串一组）：
   - 这一组有任何节点从“有用”的节点接了输入 → **没用分支**（上黄色）
   - 否则 → **漂浮**（上紫色）
3. 子网络当成一个节点，不进去。sticky note、network box 不当节点，不删。空出来的 network box 保留。

### 弹窗

- 列表一组一行，可展开看里面的节点；默认全部勾上。显示状态（漂浮/没用分支）和节点数。
- 按钮：一键全部高亮（选中并让网络编辑器框住）、上色、恢复颜色、删除。
- 上色前把原颜色记在节点 userData（`hipcheck_orig_color`），恢复后清掉这个记录；存盘再开也能恢复。
- 上色和删除各自放进一个撤销组，Ctrl+Z 一次撤回。
- hip 从没存过盘时，删除按钮灰掉，提示先存盘。

### 删除流程

1. 弹确认框：“将删除 N 个节点，会先备份，确定？”
2. 用 Houdini 自带备份 `hou.hipFile.saveAsBackup()`，按 Houdini 自己的备份规则存。保护：
   - 工具从不保存主 hip。
   - 调用前记下备份目录里已有的文件；如果返回的备份路径原本就存在（等于会覆盖），停下并报错，不删除。
   - 调用后确认备份文件真的存在，才继续。
3. 在撤销组里删除勾选的节点。
